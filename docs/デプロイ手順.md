# Vercel デプロイ手順（apps/admin）

事前: Git リモート（GitHub など）にリポジトリを push しておく。現在リモートは未設定。

1. Vercel で New Project → リポジトリを選ぶ。
2. **Root Directory = `apps/admin`**、Framework は Next.js（自動検出）。
   - モノレポの `packages/widget`・`packages/shared` を使うため「Include source files outside of the Root Directory」を ON にする。
3. Environment Variables（Production）:

| 名前 | 値 | 備考 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase の URL | ブラウザに出てよい |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon キー | ブラウザに出てよい |
| `SUPABASE_SERVICE_ROLE_KEY` | service role キー | **サーバーのみ** |
| `ANTHROPIC_API_KEY` | Claude API キー | **サーバーのみ** |
| `ANTHROPIC_MODEL` | `claude-haiku-5-5` など | 未設定なら `claude-opus-5-5` |
| `ALLOWED_ORIGINS` | 埋め込み元のオリジン（カンマ区切り） | **本番で未設定だと全オリジン拒否**。デモだけなら管理画面と同一オリジンなので不要 |

4. Deploy。完了後、`https://<ドメイン>/demo` で 💬 が出ることを確認。
5. Supabase 側: Authentication → URL Configuration の Site URL を本番 URL にする。匿名サインインを ON にする。
6. 通し確認: `/demo` で質問 → AI 回答、FAQ 外の質問 → 管理画面 `/conversations` に現れる、など（`受け入れ確認.md` の 3〜6）。

## 実施記録（Vercel CLI）
- 本番 URL: https://fullstack-cs-chatbot.vercel.app （デモ: `/demo`、管理画面: `/login`）
- `npx vercel link` → Root Directory を `apps/admin`、Framework を Next.js に設定 → `npx vercel env add <名前> production`（`SUPABASE_SERVICE_ROLE_KEY` と `ANTHROPIC_API_KEY` は `--sensitive`）→ `npx vercel deploy --prod`。
- `ALLOWED_ORIGINS` は未設定（デモは同一オリジンのため不要。他サイトへ埋め込むときに設定する）。
- `.vercel/` は git 管理外。`vercel link` が `.gitignore` に追加する `.env*` は `.env.example` まで除外するので入れない。
- Windows の Git Bash で `vercel api /v9/...` を使うときは、先に `export MSYS_NO_PATHCONV=1` を実行する（パスが変換されるため）。
